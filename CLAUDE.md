# CLAUDE.md

`dev-evening` is a **content-only** repo — monthly Kotlin/Android video link lists for the "Android Evening" meetup.
No build system, no tests, no source code. Do not search for `package.json`, `build.gradle`, `Makefile`, etc.

## Layout

- `README.md` — index of monthly files, grouped by year.
- `events/YYYY-MM.md` — one file per month.
- `events/extended.md` — overflow content not used in meetings.

To scaffold the next month's file, use the `create-new-template` skill.
